# Таблиця токенів

Усі токени системи в одній таблиці, зібрані з `tokens.json` (147 рядків). Порядок — як у файлі: кольори, тіні, відступи, кути, лінії, розміри, точки переходу, розміри шрифтів, родини шрифтів, стилі тексту.

- **Світла / синя секція** — значення в темі `light` і в темі `blue` (`data-theme="blue"`). Для кольорів, заданих посиланням на інший токен, показано підсумковий колір, а в дужках — токен, на який посилається.
- Токени без окремих значень для тем (палітра, відступи, розміри, шрифти) діють однаково в обох секціях, тому значення повторено.
- Порожня клітинка в «Де використовується» означає, що в `tokens.json` опису немає.
- Стилі тексту записано як «розмір / інтервал, насиченість[, трекінг], родина».
