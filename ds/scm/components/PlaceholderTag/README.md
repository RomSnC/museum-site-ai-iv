# PlaceholderTag

Пунктирна позначка «ТИМЧАСОВО» біля вмісту-заглушки — тексту, фото, ціни, розкладу, адреси.

- Без дітей показує «тимчасово» / «placeholder» залежно від `lang`; можна передати свій текст («Фото — тимчасово»).
- Прибирайте позначку разом із заміною вмісту на справжній. Перед запуском на сторінці не має лишитися жодної.
