# Window

Рамка «вікна старої ОС» — основа всіх карток, форми й контактів: рамка `border-frame`, рядок заголовка в інверсії, жорстка тінь.

- `title` — «назва файлу» в рядку заголовка (`excursion.exe`, `readme.txt`); `titleIcon` — піксельна іконка перед нею.
- `controls={false}` прибирає три декоративні квадрати (на смартфоні вони ховаються самі).
- `media` — вміст між рядком заголовка й тілом без відступів (фото експоната).
- `as` — тег обгортки (типово `article`; для форми й повідомлень — `div`).
- Квадрати в рядку заголовка — декор: не робіть їх кнопками й не вішайте на них дій.
